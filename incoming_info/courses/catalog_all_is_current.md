## 100-Level

- **Credits:** 3 (3;0;0)

## 200-Level

### IS 218 — Building Web Applications
- **Credits:** 3 (3;0;0)
- **Prerequisites:** IS 117 or IT 202; and CS 100/113/115
- **Description:** Hands-on design of web-based information systems. Working in teams, building multiple web apps, usability evaluation, use of an open-source CMS.
- **Catalog link:** https://catalog.njit.edu/undergraduate/computing-sciences/informatics/

### IS 219 — Adv Website Development
- **Credits:** 3 (3;0;0)
- **Prerequisites:** IS 117 or IT 202; and CS 100/113/115. IS 218 strongly encouraged.
- **Description:** Advanced interactive websites focused on client-side scripting. Dynamic UI patterns, usability, security/privacy, cross-browser, JS/DOM/jQuery, validation, cookies, basic server communication, AJAX.
- **Catalog link:** https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 247 — Designing the User Experience
- **Credits:** 3 (3;0;0)
- **Prerequisites:** None listed
- **Description:** Design and evaluation of human–computer interfaces for interactive systems. Interface approaches (menus, commands, direct manipulation), screen layout, metaphors, human information-processing models, evaluation methods (protocol analysis, monitoring, surveys), documentation/help requirements. Students create and assess interface mockups.
- **Catalog link:** https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/
- **⚠️ Ownership:** HCI program controls this course. Cannot modify.

### IS 425 — Enterprise AI Applications & Infrastructure
- **Credits:** 3 (3;0;0)
- **Prerequisites:** IS 331 or CS 331 or MIS 385

- **Catalog link:** https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 448 — Usability & Measuring UX
- **Credits:** 3 (3;0;0)
- **Prerequisites:** One stats course (MATH 105/120/225/244/279/305/333/IE 331/ECE 321/MNET 315); and IS 247
- **Description:** Quantitative methods for measuring usability and UX. Experiments (A/B testing), metrics (NPS, SUS). Students design, run, and analyze surveys. Descriptive and inferential statistics for interpreting and communicating results.
- **Catalog link:** https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/
- **⚠️ Ownership:** HCI program likely controls this course.

### IS 480 — Data-Centric AI
- **Credits:** 3 (3;0;0)
- **Prerequisites:** DS 100 or CS 100; and MATH 105 or MATH 333; and IS 331 or CS 331 or MIS 385; and IS 465 or CS 375
