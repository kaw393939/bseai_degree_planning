# Current NJIT course catalog (EAI spine courses)

Date compiled: 2026-02-20

This document records a **paraphrased** snapshot of NJIT catalog information for the core spine courses in the BS in Enterprise AI planning.

Sources were collected using `eai search` restricted to `njit.edu` and saved (untracked) under `incoming_info/njit_course_research/`.

## Current courses (official)

### IS 117 — Introduction to Website Development

- Credits: 3 (3;0;0)
- Catalog focus (paraphrase): planning/designing/building websites; requirements, mockups/usability considerations; implementing multi-page sites with HTML/XHTML + CSS with attention to compatibility.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 218 — Building Web Applications

- Credits: 3 (3;0;0)
- Prereqs (catalog): IS 117 or IT 202; and CS 100/113/115
- Catalog focus (paraphrase): hands-on design of web-based information systems; working in teams; building multiple web apps; usability evaluation; use of an open-source CMS.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/informatics/

### IS 219 — Advanced Website Development

- Credits: 3 (3;0;0)
- Prereqs (catalog): IS 117 or IT 202; and CS 100/113/115. IS 218 strongly encouraged.
- Catalog focus (paraphrase): advanced interactive websites focused on client-side scripting; dynamic UI patterns; usability; security/privacy; cross-browser; JS/DOM/jQuery; validation, cookies, basic server communication, AJAX.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 265 — Introduction to Information Systems

- Credits: 3 (3;0;0)
- Catalog focus (paraphrase): role of information systems in organizations; evolving nature of IT; use of computer tools for analysis and presentation. (Also includes credit-exclusion notes vs MIS 245.)
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 331 — Database Design, Management and Applications

- Credits: 3 (3;0;0)
- Prereqs (catalog): IS 218 or IT 202
- Catalog focus (paraphrase): relational database design/management using SQL; ER modeling; normalization; improving poor designs; advanced SQL (joins/subqueries) for business decision-making.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

### IS 390 — Requirements Analysis and Systems Design

- Credits: 3 (3;0;0)
- Prereqs (catalog): CS 103/113/115 and IS 218 or IT 202
- Catalog focus (paraphrase): systems development life cycle from requirements through design; elicitation/fact-finding; structured analysis tools; prototyping; CASE overview; UI and output design.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/informatics/

### IS 425 — Enterprise AI Applications & Infrastructure

- Credits: 3 (3;0;0)
- Prereqs (catalog): IS 331 or CS 331 or MIS 385
- Catalog focus (paraphrase): advanced hands-on course connecting AI to enterprise systems; design/deploy/manage AI solutions; real-time ingestion; advanced ETL; vector databases; human-in-the-loop workflows; cost/quality optimization.
- Official catalog area link (course listed within): https://catalog.njit.edu/undergraduate/computing-sciences/information-systems/

## Notes

- Catalog wording and prerequisites can change year to year; treat this as a snapshot.
- Studio delivery (caps, rubrics, checkoffs) is a program design choice layered on top of these catalog descriptions.
