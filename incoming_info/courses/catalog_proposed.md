# Proposed courses and proposed changes (EAI spine)

Date compiled: 2026-02-20

This document describes what is **proposed** (not yet official catalog text).

## Proposed new course

### IS 118 (Proposed) — Web Systems + JavaScript Foundations (Studio)

Purpose: make IS117 broad/vocabulary-heavy and portfolio-oriented, then make IS118 the first “serious build” studio so downstream courses can assume students can run, debug, and ship.

Proposed focus:

- JavaScript fundamentals (functions, arrays/objects, control flow)
- DOM + events, forms + validation
- JSON + `fetch`, basic client-side state
- Debugging workflow (browser devtools + VS Code)
- Intro to security hygiene (secrets, basic threat awareness, safe default habits)
- Professional workflow reinforcement (terminal, Git, deploy, documentation)

Signature deliverable:

- An interactive web product with at least one API integration, published, with a small verification/evidence package (tests or structured test checklist + “what I verified” notes).
