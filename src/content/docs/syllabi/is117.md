# IS 117 — Introduction to Website Development

**Studio label:** Inquiry & Web Craft
**Credits:** 3 | **Contact hours:** 3 hrs/week | **Mode:** Studio (face-to-face)
**Human Edge capability:** Disciplined Inquiry
**40/60 split:** Manual web development / AI-assisted building
**Prerequisites:** None

<Aside type="tip" title="Position in the spine">
This is **Studio 1** — the entry point. Students arrive with zero assumed technical knowledge and leave with a deployed portfolio, a museum-style website, and the questioning discipline that makes everything else possible.
</Aside>

---

## Course Description

This course boots students from "zero" to a functional baseline for building and presenting simple web products. Students learn essential professional tooling (Linux/terminal, VS Code, Git/GitHub, deployment), web fundamentals (HTML, CSS, introductory JavaScript), and the vocabulary and mental models required to make and critique products.

The course is intentionally "whole person" and portfolio-oriented. Students leave with two published artifacts:

1. A **museum-style single-topic website** (design/psychology/technology theme)
2. A **personal portfolio site** they continue to evolve across the degree

Technical skill building is required, but the course emphasizes **conceptual frameworks and vocabulary** — asking good questions, usability basics, design history, persuasion principles, and brand archetypes — to help students reason about products and communicate professionally.

---

## Why Disciplined Inquiry?

AI can answer any question you ask. It cannot tell you whether you're asking the **right** question.

The first Human Edge capability is learning how to ask structured, productive questions — using issue trees, hypothesis-first thinking, and the Five Whys. Students who master this capability can direct AI assistants effectively from day one, because they understand that the quality of the output depends entirely on the quality of the input.

---

## Course Learning Outcomes

By the end of this course, students will be able to:

1. **Navigate** a Unix-style filesystem using terminal commands (Apply)
2. **Use** Git and GitHub for version control including branching, committing, and pull requests (Apply)
3. **Create** valid, semantic HTML documents with appropriate structure and accessibility (Create)
4. **Design** CSS layouts using modern techniques — flexbox, grid, responsive design (Create)
5. **Deploy** a static website to a production hosting environment (Apply)
6. **Formulate** structured questions using issue trees, hypothesis-first thinking, and the Five Whys (Analyze)
7. **Construct** a basic Context Pack for an AI-assisted web project (Apply)
8. **Evaluate** AI-generated HTML/CSS for correctness, accessibility, and maintainability (Evaluate)
9. **Explain** at a conceptual level how LLMs work — tokens, context windows, probability, limitations (Understand)
10. **Apply** foundational design psychology concepts (perception, cognitive load, visual hierarchy) to web layout decisions (Apply)

## Key Deliverables

### Portfolio Website (25%)
A professional portfolio site that evolves throughout the term and across the EAI program. Includes academic/career planning content.

### Museum Website (35%)
A museum-style website organized as a "digital exhibit" around a theme the student chooses (design movement, psychology of design, or technology history). Includes citations, clear information architecture, and a "what I learned" reflection.

### Context Pack v1
The first iteration of the program's signature recurring artifact. At this level: Project Brief + basic requirements.

## The 40/60 Split in Practice

| Component | Hard-Way (40%) | Agentic (60%) |
|-----------|---------------|---------------|
| HTML/CSS | Write semantic markup by hand; debug layout issues manually | AI-assisted page generation; rapid prototyping of layouts |
| Git | Manual commits, branching, merge conflict resolution | AI-assisted commit messages, branch management |
| Design | Hand-sketch wireframes; manual usability checks | AI-generated design variations; automated accessibility audits |
| Content | Research and write museum exhibit text; proper citations | AI-assisted content organization; grammar and clarity checking |
