# Course Catalog (New Courses)

This page lists courses requiring **new catalog entries** for the BS in Enterprise AI.

## IS 118 — Full-Stack Web Applications

IS 118 is one of two courses requiring a **new catalog entry**. The remaining 6 spine courses (IS 117, IS 218, IS 265, IS 331, IS 390, IS 425) use existing catalog numbers with updated studio-format content. See [individual syllabi](/bseai_degree_planning/syllabi/is117/) for the content of each course.

IS 118 is the bridge from "first exposure" to "real build competence."

Students learn:

- Full-stack web application architecture
- Automated testing (unit, integration) and CI/CD pipelines
- Code review and AI output evaluation (AI Audit Log)
- Terminal + Git + deploy reinforcement
- Security fundamentals (authentication, secrets management)

Signature deliverable:

- Full-stack web application with automated tests, CI/CD pipeline, and AI Audit Log documenting professional judgment about AI-generated code.

## IS 482 — Community AI Training

IS 482 is the second course requiring a **new catalog entry**. It serves as Studio 8 — the final course in the spine.

Students learn:

- Curriculum design for non-technical audiences
- AI literacy pedagogy and audience analysis
- Event planning, facilitation, and accessibility
- Translating technical knowledge into actionable community resources
- Reflective practice and impact assessment

Signature deliverable:

- Live community AI training event with curriculum materials, participant feedback, and impact assessment.

## Studio expectations across the spine

- Section cap: 20–25
- Required workflow: terminal + Git + deploy
- Consistent artifacts: README + runbook + evaluation note + revision log
