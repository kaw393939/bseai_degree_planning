# Course Catalog (Proposed)

This page lists what is **proposed** (not official catalog text).

## IS 118 (Proposed) — Interactive Web Development

IS 118 is the only course requiring a **new catalog entry**. The remaining 7 spine courses (IS 117, IS 218, IS 219, IS 265, IS 331, IS 390, IS 425) use existing catalog numbers with updated studio-format content. See [individual syllabi](/bseai_degree_planning/syllabi/is117/) for the proposed content updates to each existing course.

IS118 is the bridge from “first exposure” to “real build competence.”

Students learn:

- JavaScript fundamentals + DOM/events
- JSON + `fetch` + basic state
- Debugging workflow and verification habits
- Terminal + Git + deploy reinforcement
- Intro security hygiene (secrets, safe defaults)

Signature deliverable:

- Interactive web product with at least one API integration, deployed, with evidence (tests or structured verification notes).

## Proposed studio expectations across the spine

- Section cap: 20–25
- Required workflow: terminal + Git + deploy
- Consistent artifacts: README + runbook + evaluation note + revision log
