# Outcomes & Competencies (Draft)

## Program outcomes (draft)

Graduates will be able to:

1. Ship AI software: deliver AI-enabled features with version control, testing, CI/CD, and documentation.
2. Engineer data: design and maintain data pipelines with quality checks and lineage.
3. Operationalize models: deploy inference services with monitoring, rollback strategies, and cost controls.
4. Evaluate AI: create evaluation plans and measure performance, robustness, and drift.
5. Design responsibly: apply privacy, security, and risk controls; document limitations and intended use.
6. Build products: translate stakeholder needs into requirements, prototypes, and iterative releases.

## Competency areas

- Software engineering: APIs, testing, design patterns, performance
- Systems: cloud, containers, networking, observability
- Data: SQL, modeling, ETL/ELT, warehousing/lakehouse concepts
- ML/LLMs: training basics, prompt/agent patterns, RAG, evals
- Product: discovery, metrics, experimentation, UX collaboration
- Enterprise: governance, compliance, integration, change management

## Evidence artifacts (what students should produce)

- Production-style service with tests, CI, and documentation
- Data pipeline with validation and monitoring
- Model/LLM evaluation report (metrics + failure analysis)
- Capstone product: demo, technical design, and postmortem
