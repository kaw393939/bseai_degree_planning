# Curriculum Map

This matrix shows how each student outcome progresses across the eight-course studio spine. Every outcome follows the **I → R → M** (Introduced → Reinforced → Mastered) pattern, ensuring students encounter each capability multiple times with increasing depth before it is assessed for mastery.

## Human Edge Capability Progression

Each course foregrounds one Human Edge capability while reinforcing others:

| Course | Primary Capability | What Students Learn |
|---|---|---|
| **IS 117** | Disciplined Inquiry | How to ask structured questions and evaluate answers |
| **IS 118** | Translation | How to make the invisible tangible for non-technical audiences |
| **IS 218** | Professional Judgment | When to accept, reject, or modify AI-generated work |
| **IS 265** | Problem Finding | How to identify the *real* problem before building solutions |
| **IS 219** | Resilience Thinking | How systems fail and how to plan for failure |
| **IS 331** | Epistemic Humility | What data captures, distorts, and misses entirely |
| **IS 390** | Systems Thinking | How components interact to produce emergent behavior |
| **IS 425** | Accountable Leadership | Taking ownership of systems and their real-world consequences |

## Context Pack Evolution

The Context Pack — the program's signature recurring artifact — progresses alongside outcomes:

| Course | Context Pack Scope | Components |
|---|---|---|
| IS 117 | Single page/component | Project Brief + basic requirements |
| IS 118 | Multi-page interactive app | + API documentation, interaction requirements |
| IS 218 | Full-stack application | + Architecture patterns, testing criteria, CI/CD specs |
| IS 265 | Organizational problem | + Stakeholder map, political context, assumptions log |
| IS 219 | Infrastructure system | + Failure modes, SLA requirements, runbooks |
| IS 331 | Data system | + Data assumptions, quality requirements, epistemic limits |
| IS 390 | Multi-system design | + Architecture constraints, tradeoff analysis, evaluation plan |
| IS 425 | Production enterprise system | All components integrated; client-grade documentation |

## Outcome Coverage Summary

| Metric | Value |
|---|---|
| Total ABET outcomes | 5 |
| Total Human Edge outcomes | 5 |
| Courses where each outcome appears | 5–8 |
| Minimum introductions before mastery | 3 courses |
| Mastery assessment points | IS 390 and IS 425 |
| Outcomes assessed only once | 0 |

Every outcome is introduced no later than the third course and mastered no earlier than the seventh. This ensures multiple exposures and a genuine developmental arc.
