# Course-Level Learning Objectives

Each studio course has learning objectives aligned to Bloom's Taxonomy (Remember → Understand → Apply → Analyze → Evaluate → Create). These are measurable, assessable, and mapped to both ABET student outcomes and Human Edge capabilities.

---

## IS 117 — Web Development & Inquiry

**Human Edge: Disciplined Inquiry** · **40/60 Split: Manual web dev / AI-assisted building**

By the end of this course, students will be able to:

1. **Navigate** a Unix-style filesystem using terminal commands (Apply)
2. **Use** Git and GitHub for version control including branching, committing, and pull requests (Apply)
3. **Create** valid, semantic HTML documents with appropriate structure and accessibility (Create)
4. **Design** CSS layouts using modern techniques (flexbox, grid, responsive design) (Create)
5. **Deploy** a static website to a production hosting environment (Apply)
6. **Formulate** structured questions using issue trees, hypothesis-first thinking, and the Five Whys (Analyze)
7. **Construct** a basic Context Pack for an AI-assisted web project (Apply)
8. **Evaluate** AI-generated HTML/CSS for correctness, accessibility, and maintainability (Evaluate)
9. **Explain** at a conceptual level how LLMs work — tokens, context windows, probability, limitations (Understand)
10. **Apply** foundational design psychology concepts (perception, cognitive load, visual hierarchy) to web layout decisions (Apply)

---

## IS 118 — Full-Stack Web Applications

**Human Edge: Professional Judgment** · **40/60 Split: Manual testing and review / AI-directed full-stack development**

By the end of this course, students will be able to:

1. **Build** a full-stack web application with front-end, API layer, and persistent data store (Create)
2. **Write** automated tests (unit, integration) and configure CI/CD pipelines (Create)
3. **Deploy** applications with logging, monitoring, and basic observability (Apply)
4. **Evaluate** AI-generated code for correctness, security, maintainability, and performance (Evaluate)
5. **Maintain** an AI Audit Log documenting acceptance, rejection, and modification decisions with reasoning (Evaluate)
6. **Make** tradeoff decisions (speed vs. quality, features vs. reliability) with documented rationale (Evaluate)
7. **Construct** engineering-grade Context Packs including architecture patterns and testing criteria (Create)
8. **Conduct** code reviews of both human-written and AI-generated code (Analyze)
9. **Debug** production issues using logs, error traces, and systematic investigation (Analyze)

---

## IS 218 — Infrastructure & Resilience

**Human Edge: Resilience Thinking** · **40/60 Split: Manual infrastructure / AI-directed automation**

By the end of this course, students will be able to:

1. **Administer** Linux systems including processes, permissions, networking, and security (Apply)
2. **Build** and deploy containerized applications using Docker and orchestration tools (Create)
3. **Configure** authentication, authorization, and secrets management for web services (Apply)
4. **Implement** observability (logs, metrics, traces) for a deployed system (Create)
5. **Conduct** incident drills and write honest postmortems (Evaluate)
6. **Create** a Failure Mode Analysis identifying how a system breaks, detection methods, and recovery plans (Create)
7. **Design** runbooks for operational scenarios including degraded service and recovery (Create)
8. **Construct** infrastructure Context Packs including failure modes and SLA requirements (Create)
9. **Diagnose** production incidents using systematic investigation methods (Analyze)

## IS 265 — Enterprise AI Midpoint Capstone

**Human Edge: Problem Finding** · **40/60 Split: Manual stakeholder analysis / AI-assisted prototyping**

By the end of this course, students will be able to:

1. **Identify** the real problem in an organizational context, distinguishing symptoms from root causes (Analyze)
2. **Conduct** stakeholder analysis, mapping interests, power dynamics, and contradictions (Analyze)
3. **Model** business processes using standard notation and workflow diagrams (Apply)
4. **Elicit** requirements through interviews, observation, and document analysis (Apply)
5. **Construct** a problem framing memo with constraints, assumptions, and success metrics (Create)
6. **Present** technical recommendations to skeptical stakeholders using evidence and persuasion (Create)
7. **Construct** organizational Context Packs that include human dynamics and political context (Create)
8. **Apply** persuasion frameworks (Cialdini's principles, evidence-based argumentation) to stakeholder communication (Apply)
9. **Maintain** an assumptions log tracking what was assumed, investigated, and changed (Evaluate)

## IS 482 — Community AI Training (Service Learning)

**Human Edge: Translation** · **40/60 Split: Manual curriculum design / AI-assisted material creation**

By the end of this course, students will be able to:

1. **Research** a non-technical audience's AI knowledge gaps and design workshop curricula to address them (Create)
2. **Design** hands-on exercises that make abstract AI concepts accessible to diverse audiences (Create)
3. **Deliver** live training sessions, adapting in real-time to audience questions and confusion (Apply)
4. **Write** a Translation Brief documenting what it took to make AI concepts accessible to a non-technical audience (Evaluate)
5. **Plan** event logistics including venue, outreach, registration, accessibility, and contingency (Apply)
6. **Collect** and analyze participant feedback to assess community impact (Analyze)
7. **Produce** a Community Impact Report with evidence of learning outcomes (Create)
8. **Construct** Translation-focused Context Packs that bridge technical and non-technical perspectives (Create)
9. **Reflect** on the gap between expert understanding and public comprehension of AI (Evaluate)

---

## IS 331 — Data & Knowledge Systems

**Human Edge: Epistemic Humility** · **40/60 Split: Manual SQL and schema design / AI-directed pipeline building**

By the end of this course, students will be able to:

1. **Design** relational database schemas that model real-world domains with appropriate normalization (Create)
2. **Write** SQL queries including joins, aggregations, subqueries, and window functions (Apply)
3. **Build** data pipelines with validation, quality checks, and error handling (Create)
4. **Explain** graph databases and knowledge graphs as data structures for representing relationships (Understand)
5. **Explain** vector embeddings as data structures for representing semantic similarity (Understand)
6. **Implement** hybrid retrieval combining metadata filtering, semantic search, and optionally graph traversal (Create)
7. **Document** data assumptions — what a dataset captures, what it distorts, and what's missing (Evaluate)
8. **Compare** data structures (B-trees, hash maps, graphs, vectors) as *theories* about what matters (Analyze)
9. **Apply** data quality principles including reproducibility, validation, and governance (Apply)
10. **Construct** data-aware Context Packs that explicitly address epistemic limitations (Create)

---

## IS 390 — Systems Analysis & Design

**Human Edge: Systems Thinking** · **40/60 Split: Manual analysis and diagramming / AI-directed design documentation**

By the end of this course, students will be able to:

1. **Decompose** complex systems into components, interfaces, and dependencies (Analyze)
2. **Write** requirements documents with traceability to stakeholder needs and acceptance tests (Create)
3. **Design** system architectures accounting for performance, reliability, cost, and user impact (Create)
4. **Analyze** tradeoffs between competing design approaches with documented reasoning (Evaluate)
5. **Create** evaluation plans defining what "good" means, how it's measured, and what can go wrong (Create)
6. **Identify** emergent behavior and failure modes that only become visible at the system level (Analyze)
7. **Account** for AI components with probabilistic behavior in systems analysis (Analyze)
8. **Build** prototypes demonstrating key architectural decisions (Create)
9. **Construct** systems-level Context Packs including architecture constraints and tradeoff analysis (Create)

---

## IS 425 — Applied Enterprise AI

**Human Edge: Accountable Leadership** · **40/60 Split: Manual KG design and HITL architecture / AI-directed system integration**

By the end of this course, students will be able to:

1. **Build** a production-quality AI system integrating knowledge graphs, vector retrieval, and HITL workflows (Create)
2. **Design** and implement evaluation harnesses with regression gates (Create)
3. **Deploy** an AI system with observability including decision tracing, failure logging, and human override tracking (Create)
4. **Present** a system to industry stakeholders at Demo Day, defending design decisions with evidence (Create)
5. **Write** honest postmortems identifying what worked, what failed, and what to improve (Evaluate)
6. **Take accountability** for system outcomes including failures, biases, and unintended consequences (Evaluate)
7. **Manage** a real client relationship including expectations, feedback, and delivery (Apply)
8. **Construct** production-grade Context Packs synthesizing domain knowledge, system architecture, and evaluation criteria (Create)
9. **Reflect** on leadership decisions and their impact in a formal Leadership Reflection artifact (Evaluate)
