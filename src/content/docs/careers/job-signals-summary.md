# Job Signals Summary (sanitized)

This is a **non-verbatim** summary of roles observed in recent AI-focused job postings (2024–2025). It exists to translate job-posting signals into curriculum-relevant takeaways.

## Roles seen (examples)

- **Forward-Deployed AI Engineer** (financial workflows, embedded with PM/UX): $145k–$183k base shown in one posting.
- **Product Engineer – AI** (full-stack + AI frameworks/tools): $180k–$220k base shown in one posting.
- **AI Deployment Engineer (Gov / regulated)** (safe & effective GenAI deployment): $137k–$250k base shown in one posting.
- **AI Engineer** (product-embedded, design/PM collaboration): $175k–$350k base shown in one posting.
- **Software Engineer, AI Product** (LLM features + evals + agentic workflows): salary not shown in the captured excerpt; skills emphasize production deployment and iteration.

## Skills that repeat across these roles

- **Cross-functional delivery**: work with PM/design/research; write clear handoffs and technical docs.
- **LLM application engineering**: build LLM-backed features; design prompts and tool-use workflows.
- **Evaluation**: build internal evals; iterate to improve quality and reduce risk.
- **Production readiness**: deploy to real systems; care about reliability, performance, and costs.
- **Modern software engineering**: strong Python + API skills; pragmatic engineering discipline.

## Curriculum implications (draft)

- Teach **prototype → production** explicitly, not just notebooks.
- Make **evaluation and AI QA** a first-class outcome (datasets, metrics, regression tests).
- Ensure students can ship **LLM-backed workflows** with guardrails and documentation.
