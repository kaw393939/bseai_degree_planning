# BS in Enterprise AI (NJIT Informatics) — Planning Repo

This repository contains working materials for planning a BS in Enterprise AI.

## Website (Astro)

The website is an Astro + Starlight docs site.

- Content lives in `src/content/docs/`
- Build output is `dist/`

### Local dev

- `npm install`
- `npm run dev`

### Deploy

Deployment uses GitHub Actions to publish to GitHub Pages.
