# Program Overview (Draft)

## Working description

A practice-focused undergraduate program that blends software engineering, data/AI fundamentals, product thinking, and enterprise systems.

## Graduate profile

Graduates should be able to:

- Build and deploy AI-enabled applications with strong software engineering practices
- Design data pipelines and model-inference services that are reliable, observable, and secure
- Evaluate model quality and risk (bias, privacy, misuse) and document decisions
- Work cross-functionally using product requirements, experimentation, and iteration

## Pillars

1. **Software engineering for AI systems**
2. **Data engineering & MLOps foundations**
3. **Applied ML/LLMs and evaluation**
4. **Product engineering and human-centered design**
5. **Enterprise context: security, governance, compliance, and integration**
