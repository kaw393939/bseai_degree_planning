## Issue 1: No Human Edge Artifact in Grade Breakdown (HIGH)

Grade breakdown: Checkoffs 15%, Vocabulary 10%, Labs 15%, Portfolio 25%, Museum 35%.

The assessment plan requires "Human Edge Artifact: 20–25%." There is no line item for it. The "Inquiry Journal" is described in the syllabus body as a key deliverable but has no grade weight. If Disciplined Inquiry is the Human Edge capability, the Inquiry Journal is presumably the Human Edge artifact — but a reviewer will ask: "Where's its grade?"

**Fix:** Either add "Inquiry Journal" as a graded line item (adjusting other weights), or explicitly note that inquiry is assessed _within_ the Museum and Portfolio projects (e.g., "Museum Website includes Inquiry Journal component").

## Issue 4: Cialdini Coverage Overlap with IS 265 (LOW)
