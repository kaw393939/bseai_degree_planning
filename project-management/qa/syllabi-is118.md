## Issue 1: Demo Day in Year 1 Spring (HIGH)

"Demo Day Presentation (15%)" is a graded component. But this is IS 118 — Spring of Year 1. Multiple pages state "Demo Day starting Year 2." This is a direct contradiction.

See cross-cutting Demo Day issue.

**Fix:** Either remove Demo Day from IS 118's assessment and replace with a "Final Presentation" (different label, different weight), or update all references from "starting Year 2" to "starting Semester 2."

## Issue 2: No Context Pack in Grade Breakdown (HIGH)

**Fix:** See cross-cutting assessment alignment issue.

## Issue 3: "Only genuinely new course" Claim — Verify (MEDIUM)

The Aside says IS 118 "is the only genuinely new course proposed for the spine." This is consistent with the program's messaging. However, IS 425 is described as "existing number with updated content" — if the content update is substantial, someone might argue there are effectively 2 new courses.

**Fix:** Consider softening to "the only new catalog number" or "the only course requiring a new catalog entry."
