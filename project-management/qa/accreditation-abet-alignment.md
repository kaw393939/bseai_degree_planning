# QA: ABET Alignment

**Page:** `src/content/docs/accreditation/abet-alignment.md`
**Status:** PASS — Minor note only

The ABET SO mapping is thorough with primary and supporting course assignments. The only consideration: the mapping assumes IS 350 (Computers, Society & Ethics) as the ethics anchor, but IS 350 is not part of the 8-course studio spine. If IS 350's content ever changes or the course is dropped from the curriculum, the ethics/society outcome (SO-4) loses its primary anchor. This is a design risk, not a QA issue.

No changes required.
