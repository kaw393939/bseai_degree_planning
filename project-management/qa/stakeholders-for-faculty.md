# QA: For Faculty

**Page:** `src/content/docs/stakeholders/for-faculty.md`
**Status:** Issues found

---

## Issue 1: "Every course ends with some form of Demo Day" (HIGH)

This contradicts "Demo Day starting Year 2" stated in `core-studio-spine.md`, `overview.md`, `msche-alignment.md`, and `assessment-plan.md`.

Even more problematically, IS 117's syllabus has no Demo Day component — it has a "short presentation" in Week 15 at most. If this page tells faculty "every course" has Demo Day, but the IS 117 syllabus and multiple planning docs say it starts in Year 2, you have a direct contradiction a faculty senate committee will spot.

**Fix:** Either:
- Change to "Every course from IS 118 onward ends with Demo Day; IS 117 ends with a final presentation"
- Or change the program constraint to "Demo Day starting Semester 2" and keep this language

---

## Issue 2: "2-hour lab block" — Contact Hours Discrepancy (MEDIUM)

"In a typical 2-hour lab block (75 min lecture + 45 min lab)" — but all syllabi state "Contact hours: 3 hrs/week." Is the studio a 2-hour block or a 3-hour block?

This matters for room scheduling, faculty load calculations, and ABET credit-hour compliance.

**Fix:** Clarify the actual meeting pattern. If it's a single 3-hour studio meeting, update this example. If it's a 75-min + 45-min split within a single 2-hour block, explain where the 3rd contact hour comes from (is it offset by out-of-class work?).

---

## Issue 3: "40/60 Split" Example Doesn't Mention Assessment (LOW)

The faculty guide describes the 40/60 split pedagogically but doesn't explain how faculty should _grade_ the 40% vs 60% work. Since the assessment plan has separate categories (Deployed Artifact, Human Edge Artifact, etc.), faculty might wonder: "Do I grade the hard-way and agentic portions separately?"

**Fix:** Add one sentence: "The 40/60 split is a pedagogical guideline for time allocation, not a grading split. See the assessment plan for grading categories."
