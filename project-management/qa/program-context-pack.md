# QA: The Context Pack

**Page:** `src/content/docs/program/context-pack.md`
**Status:** Issues found

---

## Issue 1: Context Pack Grading Rubric Not Reflected in Any Syllabus (HIGH)

This page defines a 4-criterion rubric (Completeness 25%, Specificity 25%, Eval Criteria Quality 25%, Evolution 25%) and states Context Packs are "assessed, graded, and accumulated."

**No syllabus has a separate "Context Pack" grade line item.** The assessment plan says Context Pack should be 10–15% of the grade, but no syllabus allocates weight to it.

This is a significant gap. The program's signature artifact has no visible assessment weight in any individual course.

**Fix:** Either (a) add "Context Pack" as an explicit graded line item in each syllabus, or (b) clarify in this document that Context Pack assessment is folded into the broader project grade, specifying which grade component absorbs it.

---

## Issue 2: IS 117 Context Pack Example Underestimates (LOW)

The page shows IS 117's Context Pack as:
```
Project Brief: Build a museum-style website about [topic]
Domain Context: HTML structure, CSS layout principles, target audience
Evaluation Criteria: Valid HTML, responsive layout, accessible navigation
Prior Context: N/A (first project)
```

This implies a simple one-page output, but the IS 117 syllabus describes a "Context Pack v1" as a key deliverable. The example should feel like a real artifact, not a 4-line stub.

**Fix:** Expand the example slightly or note "the full Context Pack v1 is typically 1–2 pages."
