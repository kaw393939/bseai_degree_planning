## Issue 1: HE-4 (Epistemic Responsibility) Introduced in IS 117? (MEDIUM)

The Human Edge Outcomes table shows HE-4 as "I" (Introduced) in both IS 117 and IS 118, with the **bold primary** marker on IS 331.

But IS 117 teaches Disciplined Inquiry, not Epistemic Responsibility. The idea that epistemic awareness is "introduced" in IS 117 through questioning discipline is defensible but unusual — a reviewer might expect HE-4 to first appear in IS 218 (where students start evaluating AI output) or IS 331 (its primary course).

**Fix:** Reconsider whether IS 117 truly introduces HE-4, or if the "I" should start at IS 218.

## Issue 2: Context Pack Evolution Table — Scope Descriptions (LOW)

The Context Pack Evolution table describes IS 117's scope as "Single page/component" but the IS 117 syllabus has students building two multi-page websites (portfolio + museum). The scope is broader than "single page/component."
